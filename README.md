# TXL Creator Hub

A mobile-friendly creator dashboard for 2xlamar/TXL.

## Deploy on Railway
1. Upload these files to a GitHub repository.
2. In Railway choose **New Project → Deploy from GitHub repo**.
3. Select this repository.
4. Railway installs dependencies and runs `npm start`.
5. Open **Settings/Networking → Generate Domain** to get your public URL.

The app currently stores dashboard edits in the browser's localStorage. Official platform APIs can be connected later with authorized credentials.
